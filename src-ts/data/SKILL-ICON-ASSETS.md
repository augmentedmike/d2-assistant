# Skill tree icon assets

The 210 classic Lord of Destruction skill icons in `public/skill-icons/` were extracted from a locally installed Diablo II game (`d2data.mpq`, `d2exp.mpq`, and `Patch_D2.mpq`). The skill-to-frame mapping follows the `IconCel` field in the game's `SkillDesc.txt` and the class icon sheets under `data/global/ui/SPELLS/`.
