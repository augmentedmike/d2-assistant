# D2 Assistant — Development Plan

This plan is intentionally user-facing and contains no machine-specific save paths or private character data.

## Shipped

- Local character scanning and a read-only character overview.
- Searchable, filterable item bank with persistent multi-selection.
- Supported `.d2x` stash import with a verified backup.
- Item transfer into `_d2a` character copies with validation.
- Character class/level compatibility filters where requirements are known.
- Offline runeword recipe catalog with game/mode labels.
- Local feature-set preference for optional D2R/Reign recipe references.
- Transparent D2A emblem, platform icon pack, and dark steel / blood-red / ember visual palette.
- Public contribution guide and feature voting process.
