# Security policy

D2 Assistant processes local character and stash files. Do not attach personal saves, database files, or backups to a public issue.

For a security or data-loss concern, use GitHub's private vulnerability reporting for this repository if available. Otherwise, contact the maintainer through the address listed on the GitHub profile. Include the affected version, platform, and steps to reproduce; remove personal file contents and paths.

The project is an early release and does not promise that every save format or game version is supported. Keep independent backups before importing or transferring items.
